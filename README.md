# 小牛牛，Kiss Kiss ♡

文文送给牛牛的粉白色互动小网站。原生 HTML、CSS、JavaScript，无需构建。

## 互动

- 点击“收下文文的亲亲”会飘出爱心并累计亲亲数量。
- 点击信封爱心，打开文文的问题。
- 首次选择 A / B / C：嘻嘻，寒假等着被我狠狠奖励吧。
- 首次选择 D：行，寒假等着被我狠狠惩罚吧；可再做一次。
- 连续选择 D：惩罚时间×2、×3……。
- 选择过 D 后改选 A / B / C：骗牛牛的，选对了我也惩罚你，嘻嘻。
- 刷新页面后重新开始，不收集或上传回答。

支持手机、键盘操作和减少动态效果系统偏好。角色为自绘 SVG 同人装饰，相关角色归原权利人所有；本项目为个人赠礼，非官方作品。
